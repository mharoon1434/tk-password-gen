## 📌 Overview

This project is a desktop-based Password Generator Application developed using Python Tkinter GUI.

The application allows users to generate strong and secure passwords with customizable options such as:

- Uppercase Letters
- Lowercase Letters
- Numbers
- Symbols
- Adjustable Password Length

The project features a clean and modern dark-themed interface for a professional user experience.

✔ Modern GUI using Tkinter

# 🚀 How To Use

### Step 1
Select the password length using the slider.

### Step 2
Choose the character types:
- Uppercase
- Lowercase
- Numbers
- Symbols

### Step 3
Click the **GENERATE PASSWORD** button.

### Step 4
Your generated password will appear instantly.
